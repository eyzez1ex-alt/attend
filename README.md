# RU here? — واجهة إدارة الحضور

واجهة عربية RTL لإدارة الحضور والإجازات، مبنية بـ React وTypeScript وVite. المشروع أمامي فقط؛ لا يوجد تسجيل دخول فعلي أو قاعدة بيانات أو تخزين للخادم.

## التشغيل المحلي

```sh
npm install
npm run dev
```

افتح عنوان Vite المحلي الظاهر في الطرفية. أنشئ نسخة إنتاجية باستخدام `npm run build`، أو عاينها عبر `npm run preview`.

## الصفحات

- تسجيل الدخول: نموذج جاهز لواجهة المصادقة، ولا يقبل حسابات تجريبية.
- المشرف: نظرة عامة، الموظفون، الحضور، الموقع، الإجازات، العطلات المصرية، التقارير، وصلاحيات المشرفين.
- الموظف: الرئيسية، سجل الحضور، الإحصائيات، الإجازات، والملف الشخصي والجهاز.

يمكن التنقل بين مساحتي المشرف والموظف لمعاينة التصميم فقط؛ لا يطبق ذلك صلاحيات أو مصادقة. الحساب المحدد الوحيد لمنح صلاحية المشرف هو `yusufgibrel3@gmail.com`، لكن API يجب أن يثبت هذه الهوية ويطبقها على الخادم قبل تفعيل المنح أو السحب.

تقرير الحضور الشهري يتضمن واجهة جلب وتنزيل Excel-compatible CSV وحفظ PDF، وأرشيفاً للمشرفين. إنشاء التقرير تلقائياً بعد إغلاق الشهر وإتاحته للمشرفين يتطلب مهمة مجدولة وخدمة خلفية؛ المتصفح وحده لا ينفذها عند إغلاق التطبيق.

## البيانات والربط المستقبلي

كل القوائم تبدأ فارغة. النماذج تعرض التغييرات داخل حالة الصفحة الحالية فقط، وتوضح أن البيانات لم تصل إلى خادم. عقود الخدمات الحالية في `src/services/api.ts` توضح الدوال والأنواع المتوقعة دون تنفيذ طلبات شبكة.

قواعد أيام العمل في `src/utils/attendance.ts` تستثني العطلات الواردة من المصدر، وأيام الراحة المحددة من المؤسسة، والإجازات المعتمدة. لا توجد تواريخ عطلات أو أيام راحة افتراضية.

يُحتسب يوم الحضور المكتمل فقط عندما يحتوي سجل الموظف على وقتي تسجيل الحضور والانصراف مع حالة «حاضر» أو «متأخر». واجهة الموظف تعرض الإجراءين، ولا تتيح تسجيل الانصراف قبل تأكيد تسجيل الحضور من الخدمة.

## الموقع الجغرافي

نصف قطر النطاق ثابت عند **٦٠٠ متر** (مساحة تقريبية **١٬١٣٠٬٩٧٣ م²**). لا تُعرض إحداثيات افتراضية؛ أدخل إحداثيات تقريبية لتفعيل خريطة OpenStreetMap، ثم انقر لاختيار مركز المنشأة. تأكيد الحضور والتحقق الأمني من النطاق يجب أن ينفذه الخادم.
